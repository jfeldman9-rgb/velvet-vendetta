# Art provenance

The likeness reference for Cory and Bob is a photo supplied by Jason.
That photo is not committed to this repository and is not part of the download.

Intended likeness:

- Cory: swept light hair, clean-shaven, bright grin, plum couture, gold ornament, theatrical feathers.
- Bob: short dark hair, full beard, narrow dark shades, black agent suit, tie.

These files were drawn from that photo:
